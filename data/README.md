# Dataset Instructions

## 1. RealWaste Dataset

The RealWaste image dataset is not included in this repository
because of its size

Download it from its original source and organize it as follows;

data/
└── RealWaste/
    ├── Cardboard/
    ├── Food Organics/
    ├── Glass/
    ├── Metal/
    ├── Miscellaneous Trash/
    ├── Paper/
    ├── Plastic/
    ├── Textile Trash/
    └── Vegetation/
